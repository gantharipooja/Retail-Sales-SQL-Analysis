Retail Sales Analysis using SQL

## Project Overview
This project analyzes a retail sales dataset using SQL Server (SSMS). The project focuses on extracting meaningful business insights using SQL queries.

## Dataset
Retail Sales Dataset

## Tools Used
- SQL Server Management Studio (SSMS)
- SQL

## Analysis Performed
- Total Orders
- Total Sales
- Total Profit
- Average Profit
- Region-wise Sales
- Product Category Analysis
- Gender-wise Sales
- Customer Satisfaction Analysis
- Return Analysis
- Order Status Analysis
- Shipping Analysis
- Payment Method Analysis
- Top Customers
- Top Products

## SQL Concepts Used
- SELECT
- COUNT()
- SUM()
- AVG()
- GROUP BY
- ORDER BY
- OFFSET FETCH

## Project Outcome
This project demonstrates how SQL can be used to analyze retail sales data and generate business insights for decision-making.
